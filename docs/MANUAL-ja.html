MOMOSAI VJ 手順書音に反応するライブ映像（バンド・ダンス・弾き語り・合唱・歌・司会・展示）

音を拾って、ほぼ遅延なくプロジェクターやモニターの映像を変化させるソフトです。ネット接続もインストールも要りません。

本番のキー操作（これだけ覚えれば OK）
  • 曲の頭で →（曲名が出て、その曲の映像になる）
  • 迷ったら A（オート：自動で切り替え）
  • 何かおかしいときは B（暗転）
  • 映像を変えたいときは数字 1〜9（次のビートで切り替わる）、Shift+数字で 2 段目のシーン
  • MC の間は 0（タイトル）
  • キメで Space（フラッシュ）

1. 用意するもの

  • ノート PC（Windows または Mac）。Google Chrome を事前にインストール（会場はネットが無い想定）。Windows なら Edge でも可。
  • 電源アダプタ（バッテリー駆動だと GPU が遅くなる）。
  • HDMI ケーブル（＋必要なら変換アダプタ）。プロジェクター / 大型モニター。
  • おすすめ：USB オーディオインターフェース ＋ PA 卓のライン出力（AUX / REC OUT）からのケーブル。
    なければ PC 内蔵マイクでも動きますが、スピーカーから離れるほど音が遅れて届きます（10m で約 30ms）。
  • ダンス発表・DJ・BGM など PC で流す音に合わせるときは、ケーブル不要（入力で「PC で再生中の音」を選ぶ）。

2. つなぎ方

PA 卓の AUX / REC OUT→ ケーブル →USB オーディオ IF→ USB →ノート PC→ HDMI →プロジェクター
  • PA さんに「映像用にライン出力を 1 本ください（ステレオでもモノラルでも可）」とお願いする。
  • 2 入力のインターフェースで片方にしか挿していなくても、解析は「L+R ミックス」のままで大丈夫です。
  • 画面は「複製（ミラー）」にして、出力解像度はプロジェクターに合わせる。

3. 前日までの準備（チェックリスト）

  • dist フォルダを PC にコピー（例：C:\momosai-vj\。英数字だけの場所がおすすめ）
  • 起動して「デモ音源」で映像が動くことを確認
  • 右側のパネルでバンド名・セットリスト・ロゴ・テロップを入力（自動保存。「設定を書き出し」でバックアップ）
  • スリープ・スクリーンセーバーを OFF、ふたを閉じたときの動作は「何もしない」
  • OS の自動更新を止める。通知を止める（Windows：集中モード / Mac：おやすみモード）
  • Windows：サウンド設定 → 録音デバイスのプロパティ →「オーディオの機能拡張」を OFF
  • GPU が 2 つある PC（Windows）：設定 → ディスプレイ → グラフィック で Chrome を「高パフォーマンス」に
  • Zoom・Discord・DAW など、マイクを使うアプリは終了しておく
  • リハーサルで実際の音を入れて、感度（↑↓）と明るさ（Shift+↑↓）を合わせる
  • 可能ならリハで「遅延の測り方」（下記）を試す
  • 会場に「光の点滅にご注意ください」の掲示をお願いする（下記 18 章）

4. 当日の起動手順

  1. 電源アダプタ・HDMI・オーディオインターフェースをつなぐ。プロジェクターはゲームモード（低遅延モード）にし、台形補正やフレーム補間を OFF。
  2. Windows：start-windows.bat をダブルクリック。
    Mac：start-mac.command を右クリック →「開く」（初回のみ確認が出ます）。
    うまく開かないときは momosai-vj.html を Chrome のウィンドウにドラッグ。
  3. 右側のパネル ①で「マイク / ライン」を選び、デバイス（オーディオインターフェース名）を選んで ▶ 音声入力を開始。
    マイクの許可を聞かれたら「許可」。PC の音に合わせるときは「PC で再生中の音」→ 共有する画面で「システム音声を共有」をオン。
  4. ② で 音楽のタイプ を選ぶ（迷ったら「おまかせ」）。テンポが表示されれば拍も取れています。
  5. メーターが緑〜黄色の範囲で動き、演奏に合わせて KICK / SNARE / HAT のランプが点けば OK。
    赤（クリップ）が出る場合はインターフェースの入力ゲインを少し下げる。
  6. ショー開始（全画面） を押す。全画面・スリープ防止・Esc 長押しでのみ解除、がまとめて有効になります。
    プロジェクターを「拡張」でつないだときは、先に ④ の 出力ウィンドウを開く（2 画面）（下の 6 章）。
  7. 開演前はタイトル（バンド名）が出ています。1 曲目の頭で →。

6. 2 画面で使う（出力ウィンドウ）

プロジェクターを「拡張」（ミラーではなく）でつなぐと、操作画面を観客に見せずに済みます。

  1. ④ の 出力ウィンドウを開く（2 画面） を押す（画面が 2 つあれば、許可するとプロジェクター側に開きます）。
  2. 開いた映像だけのウィンドウをプロジェクター側へ移動してダブルクリック（または F）で全画面。
  3. 手元のウィンドウはそのまま操作・確認用（キー・パネル・メーター・D の診断）。マイクの許可を聞かれたら出力ウィンドウ側で「許可」。
  4. 出力ウィンドウを閉じると、手元のウィンドウが元の 1 画面の動作に戻ります。

7. 会場に合わせる（表示の調整）

  • G でテストパターン。格子・正円・四隅の印・明るさの段階で、位置・台形・明るさを合わせます。
  • ④ 表示：回転（縦置きモニター・逆さ吊りのプロジェクター）、左右反転（スクリーンの裏から投影）、サイズ・位置（スクリーンからはみ出すとき）。
  • カクカクするときは ⑤ 詳しい設定の「画質上限」や「フレームレート 30fps」。

8. ロゴ・テロップ・カウントダウン

  • ロゴ画像：③ の「ロゴ画像・テロップ・開演カウントダウン」から PNG などを選ぶ。タイトルでバンド名の代わりに / すべてのシーンの隅に小さく、を選べます。
  • テロップ：3 つまで文字を登録して Q W E で表示（MC の「次は〇〇です」「手拍子お願いします！」など）。
  • 開演カウントダウン：開演時刻を入れると、開演前のタイトルに「開演まで 05:00」と表示。1 曲目に進むと消えます。

9. セットリストの書き方

@band ももさいバンド
# 書き方：曲名 | シーン（番号か名前、カンマで複数） | パレット
1. 夜に駆ける | 2,6 | neon
2. ドライフラワー | 4 | sakura
3. 新曲 | | fire | notitle
@end Thank you!
  • シーンは 1〜9（または名前）。複数書くと、オートのときにその順番で切り替わります。空欄ならオートにおまかせ。
  • パレット：neon / sunset / ocean / fire / acid / mono / sakura / custom（1〜8 の番号でも可）。
  • notitle を付けるとその曲は曲名を出しません。全角の「｜」「、」「１」でも OK。
  • パネルの下に解析結果の表が出るので、赤いエラーが無いことを確認。

11. 声・司会（MC）への対応

  • 話し声の自動判別：どの音楽のタイプでも、話し声（MC・司会）を数秒で見分けます。話し声の間は、自動フラッシュ・ブレイク明けの一撃・テンポに合わせた切替を止め、子音（サ行・タ行など）をドラムとして扱いません。パネル ② の「声」の横に「話し声（MC）を検出中」と出ます。
  • MC の間はタイトル：⑤ で「MC（話し声）のあいだはタイトルにする」を ON（オート ON のとき）。話し声を検出するとタイトル（バンド名）に切り替わり、演奏が 2.5 秒続くと元のシーンに戻ります。
  • 歌（音楽のタイプ）：声の高さを検出して色に反映し、音量が下がらずに音程だけ変わるところ（レガート）でも反応します。ビブラートや合唱の和音では反応しすぎないようにしています。
  • 司会・スピーチ・朗読（音楽のタイプ）：話し声にやさしく反応。フラッシュとテンポに合わせた切替は使いません。シーンの切替もゆっくり（フェード）。
  • デモ音源で「歌」「話し声」を選ぶと、合成した声で反応を試せます（実際の声より機械的な音です）。

12. シーンの切り替え方・シーンごとの調整

  • ⑤「シーンの切り替え」：カット / 0.5〜2 秒のフェード。「音楽のタイプに合わせる」なら、ゆったりしたタイプ（アコースティック・しっとり・歌・司会）だけフェードになります。
  • ⑤「シーンごとの調整」：速さ・量・大きさ・残像などをスライダーで。「表示中のシーンに合わせる」で、いま出ているシーンの調整が出ます。設定は保存され、「既定に戻す」で元に戻ります。

13. MIDI コントローラ（割り当ての学習）

  1. ⑤ 詳しい設定の MIDI コントローラを使う を押す（初回は許可を聞かれます）。
  2. 「MIDI の割り当てを変える（学習）」を開き、割り当てたい操作の 学習 を押してから、パッド・ボタン・つまみを動かす。
  3. シーン（全 19 種）・フラッシュ・ストロボ（押している間）・暗転・曲送り・オート・タップ・パレット・テロップ・テストパターン・明るさ（つまみ）・感度（つまみ）に割り当てられます。「既定の割り当てに戻す」で最初の状態へ。

14. スマホから操作・OSC・照明（DMX）

これらは「ブリッジ」（同じ PC で動く小さなサーバー）を通します。単体アプリ版には入っていて自動でつながります。 ブラウザ版では start-bridge-windows.bat / start-bridge-mac.command で起動し（Node.js が必要）、パネル ⑦ で「ブリッジにつなぐ」を ON。

  • スマホから操作：PC とスマホを同じ Wi-Fi / LAN に。パネル ⑦ に出る URL（例：http://192.168.1.23:8787/）をスマホで開き、暗証番号（4 けた）を入れる。シーン・フラッシュ・暗転・曲送り・テロップ・ストロボ・明るさ・感度を操作でき、今のシーンと曲が表示されます。暗証番号を 10 回まちがえた端末はつながらなくなります。
  • OSC 受信（UDP 9000 番）：/vj/scene 3（番号・s1・名前）、/vj/flash、/vj/blackout 1、/vj/next、/vj/prev、/vj/auto 1、/vj/palette 2、/vj/msg 0、/vj/tap、/vj/master 0.8、/vj/sens 2、/vj/strobe 1、/vj/test。 既定では同じ PC のソフトからだけ受けます。LAN の照明卓などから受けるときは、ブリッジを --osc-lan 付きで起動（単体アプリは環境変数 MOMOSAI_OSC_LAN=1）。
  • OSC 送信：⑦ の OSC で「音の特徴量を送る」を ON にして送り先を入れると、/vj/level・/vj/low・/vj/kick・/vj/bpm・/vj/pitch・/vj/speech・/vj/onset/kick・/vj/beat などを 30 回/秒で送ります（TouchDesigner・Resolume・照明ソフト用）。
  • 照明（DMX）：⑦ の照明で ON。出力は Art-Net（LAN の照明ノードへ）か USB-DMX（Enttec DMX USB Pro 互換・Open DMX 互換）。灯体の種類（調光+RGB など）・台数・先頭の番地を合わせると、映像のパレットの色で光り、キックで 1 台ずつ順に強く光ります（1 秒に 3 回まで）。暗転・明るさ・フラッシュ（制限つき）も映像と同じ。

15. 単体アプリ版（ブラウザ不要）

リポジトリの app/ から Windows / Mac / Linux 用のアプリを作れます（cd app → npm install → npm run dist:win など）。中身は同じ映像ですが、次の点が楽になります。

  • マイク・MIDI・USB-DMX の許可を毎回聞かれない
  • 出力ウィンドウがプロジェクター側の画面に開いて、自動で全画面になる
  • 「PC で再生中の音」で、画面を選ぶ手順なしに PC 全体の音を取り込む（Windows）
  • ブリッジ（スマホ操作・OSC・Art-Net）が入っていて、自動でつながる

署名していないので、初回は Windows では「詳細情報 → 実行」、Mac では右クリック →「開く」が必要です。

16. 英語表示・ほかのブラウザ

  • パネルの一番上の「言語 / Language」で日本語・英語を切り替えられます（「自動」はブラウザの言語に従う）。スマホの操作画面はスマホの言語に従います。
  • Firefox・Safari でも動きますが、「PC で再生中の音」・MIDI（Safari）・USB-DMX・スリープ防止などが使えないことがあります。使えない機能はパネルの上に表示されます。本番は Chrome / Edge か単体アプリがおすすめです。

17. 困ったとき

症状対処
映像が音に反応しないパネル（M）のメーターを確認。動いていなければ、デバイスの選択・ケーブル・インターフェースのゲイン。PA のライン出力がミュートになっていないか。動いているのに反応が弱ければ ↑ で感度を上げる
反応しすぎる / 小さな音でも光る↓ で感度を下げる。会場のざわざわで反応するときは ⑤ 詳しい設定の「無音とみなす音量」を右へ
ドラムの無い曲で反応が弱い② 音楽のタイプを「アコースティック」か「しっとり」に
MC（話し声）でフラッシュが出る・シーンが変わる話し声の判定に 2〜3 秒かかるので、話し始めに 1 回出ることがあります。MC が長い本番は ⑤「MC（話し声）のあいだはタイトルにする」を ON。MC 中は 0（タイトル）も確実
歌なのに「話し声」と判定される音程の揺れが大きい歌（ラップ・語り）は話し声と判定されることがあります。② を「歌」にすると、話し声の判定に関係なく歌として反応します
スマホの操作画面が開かないPC とスマホが同じ Wi-Fi か確認。PC のファイアウォールで 8787 番（TCP）を許可。パネル ⑦ に URL と暗証番号が出ているか確認

18. 光の点滅について（安全）

強い光の点滅は、光感受性発作（いわゆるポケモンショック）を起こすことがあります。このソフトは、全画面の強いフラッシュ・反転・ストロボを 1 秒に 3 回までに自動で制限し、鮮やかな赤の点滅は白に置き換えます（NHK・民放連のガイドラインと WCAG 2.3.1 に沿った設計で、 全シーンを自動テストで確認しています）。それでも念のため、会場や受付に「演出で光の点滅があります」と掲示してもらうのがおすすめです。 気分が悪くなった方がいたら、すぐ B（暗転）。小さなお子さんが多い会場や式典では ⑤ の「フラッシュを一切使わない」と「動きの大きさ」を下げるのがおすすめです。

19. 遅延の測り方（リハーサルで）

  1. パネル ⑤ 詳しい設定で「遅延計測用の四角（右下）」を ON。ヒットのたびに右下の小さな白い四角が光ります。
  2. スマホのスローモーション撮影（240fps）で、ドラムのスティックが当たる瞬間と、スクリーンの四角が光る瞬間を同時に撮影。
  3. 動画をコマ送りして、当たったコマから光ったコマまでのコマ数 × 4.2ms が遅延です。目安は 80ms 以下（客席では音が遅れて届くので、体感はもっと小さくなります）。
  4. 大きい場合は：プロジェクターをゲームモードに / パネル ③「低遅延描画」の ON/OFF を比べる / 内蔵マイクではなくライン入力に。

20. 設定のバックアップ

パネル ⑤ 詳しい設定の「設定を書き出し」で momosai-vj-settings.json を保存できます。別の PC では「設定を読み込み」で同じ設定になります。 起動スクリプトから開いた場合、設定は dist フォルダ内の .vj-profile に保存されるので、フォルダごとコピーすれば設定も一緒に移ります。
