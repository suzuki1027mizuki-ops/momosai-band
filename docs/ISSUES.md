# 課題一覧

開発中・精査中に見つかった課題と対応状況をまとめた一覧です（2026-10-08 時点）。

| 状態 | 意味 |
|---|---|
| ✅ 解決済み | 修正済みで、再発防止のテストがあります |
| 🟡 要確認 | 自動では確かめられないので、実機・本番前に確認が必要です |
| ⬜ 未着手 | 制約か改善案で、今は対応していません |

確認方法は次のとおりです。

- **単体テスト（90 件）:** DSP・検出精度・テンポ・演出・声・話し声・ブリッジ（OSC / Art-Net / WebSocket / QR）・照明・英語の辞書・出演バンド・サウンドチェック・QR コード（jsQR で読み取って確認）
- **E2E（58 件）:** 配布用 HTML を file:// で開き、偽マイク入力で検証。光過敏・遅延・連続運転・ランダム操作 1500 回・英語表示・ブリッジ経由のスマホ操作（QR から接続）・使いやすさの機能を含みます
- **全シーンの描画確認（`npm run check-scenes`）:** バンド演奏・歌・話し声の 3 種類の音で、19 シーンの明るさと光過敏を確認し、画像を保存します
- **単体アプリの自己診断（`npm run app:smoke`）:** 仮想ディスプレイ上で起動し、偽マイク・描画・内蔵ブリッジ・出力ウィンドウの開閉を確認します
- **静的解析（ESLint）**
- **独立したコードレビュー**
