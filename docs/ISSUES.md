# 課題一覧

開発中・精査中に見つかった課題と対応状況をまとめた一覧です（2026-10-06 時点）。

| 状態 | 意味 |
|---|---|
| ✅ 解決済み | 修正済みで、再発防止のテストがあります |
| 🟡 要確認 | 自動では確かめられないので、実機・本番前に確認が必要です |
| ⬜ 未着手 | 制約か改善案で、今は対応していません |

確認方法は次のとおりです。

- **単体テスト（33 件）:** DSP・検出精度・テンポ・演出
- **E2E（34 件）:** 配布用 HTML を file:// で開き、偽マイク入力で検証。光過敏・遅延・連続運転・ランダム操作 1500 回を含みます
- **静的解析（ESLint）**
- **独立したコードレビュー**

## A. 初回の開発中に見つけて直したもの（既存の対応）

### A-1. 遅延・安定性

| # | 課題 | 状態 | 対応 |
|---|---|---|---|
| A1 | file:// では AudioWorklet を読み込めない（Blob URL でも不可を実測） | ✅ | AnalyserNode を描画フレームごとに読み出す方式にしました。データの新しさは同等です |
| A2 | AnalyserNode の既定の平滑化（0.8）と FFT の窓で、数十〜100ms 遅れる | ✅ | 平滑化を 0 にし、タイミング検出は 128 サンプル刻みの IIR フィルタで行います |
