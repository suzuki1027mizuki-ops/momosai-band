# 課題一覧

開発中・精査中に見つかった課題と対応状況をまとめた一覧です（2026-10-06 時点）。

| 状態 | 意味 |
|---|---|
| ✅ 解決済み | 修正済みで、再発防止のテストがあります |
| 🟡 要確認 | 自動では確かめられないので、実機・本番前に確認が必要です |
| ⬜ 未着手 | 制約か改善案で、今は対応していません |

確認方法は次のとおりです。

- **単体テスト（33 件）:** DSP・検出精度・テンポ・演出
- **E2E（34 件）:** 配布用 HTML を file:// で開き、偽マイク入力で検証。光過敏・遅延・連続運転・ランダム操作 1500 回を含みます
- **静的解析（ESLint）**
- **独立したコードレビュー**

## A. 初回の開発中に見つけて直したもの（既存の対応）

### A-1. 遅延・安定性

| # | 課題 | 状態 | 対応 |
|---|---|---|---|
| A1 | file:// では AudioWorklet を読み込めない（Blob URL でも不可を実測） | ✅ | AnalyserNode を描画フレームごとに読み出す方式にしました。データの新しさは同等です |
| A2 | AnalyserNode の既定の平滑化（0.8）と FFT の窓で、数十〜100ms 遅れる | ✅ | 平滑化を 0 にし、タイミング検出は 128 サンプル刻みの IIR フィルタで行います |
| A3 | 描画が一瞬止まると Analyser の窓（8192 サンプル）を超えて音を取りこぼす | ✅ | 窓を 32768 サンプル（約 0.68 秒）にしました。前回の末尾と完全一致する位置で新規分を切り出します |
| A4 | ビルド後のファイルに構文エラーがあると起動しない（重複宣言で実際に発生） | ✅ | ビルド時に全スクリプトの構文を検査し、失敗したら止めます |

### A-2. 検出精度

| # | 課題 | 状態 | 対応 |
|---|---|---|---|
| A5 | 大きなヒットで統計（σ）が膨らみ、2 打目以降のキックを取りこぼす | ✅ | 統計はしきい値で切り詰めてから更新します（ウィンソライズ）。再現率 0.80 → 1.00 |
| A6 | ハイハットの漏れでスネアを、ベースの発音でキックを誤検出する | ✅ | 帯域の最近のピークより十分小さい立ち上がりは無視します（相対ゲート） |
| A7 | 低域のエネルギーがベースの波形の位相で脈打ち、キックが埋もれる | ✅ | 直交エネルギー y²+(y'/ω)² を使います。バンド演奏でのキック再現率 0.47 → 0.88 |
| A8 | スネアの胴鳴り（185Hz）をキックとして誤検出する | ✅ | スネアの直後で、キック帯域のピークより 7dB 以上小さいものは捨てます |
| A9 | 定常ノイズ（-60dBFS）の揺らぎでキックを誤検出する | ✅ | 全体が無音のゲート外のときはオンセットを出しません |
| A10 | アクセント（キメ）がキックのたびに出る | ✅ | 「3 帯域以上が同時に立ち上がり、かつ直近のピーク + 3dB を超える一撃」に限定しました |

## C. 自動では解決できないもの（本番前に確認してください）

| # | 課題 | 状態 | 確認・回避の方法 |
|---|---|---|---|
| C1 | 実機（Windows / Mac の Chrome、USB オーディオ IF、プロジェクター）での総合遅延と動作は未検証です | 🟡 | リハーサルで、手順書 13 章（スマホの 240fps 撮影）の方法で測ってください。プロジェクターのゲームモードが一番効きます |
| C2 | 検出の調整は合成音源で行いました。実際の演奏や会場の残響では反応が強すぎる・弱すぎることがあります | 🟡 | `↑` / `↓` で感度、「音楽のタイプ」、「無音とみなす音量」で調整してください |
| C3 | 起動スクリプト（.bat / .command）を実機で実行していません（日本語を含むパス、Mac の Gatekeeper） | 🟡 | 英数字だけのフォルダに置いてください。開けないときは HTML を Chrome にドラッグしてください |
| C4 | 「PC で再生中の音」は、Mac ではブラウザのタブの音だけです（OS の制約）。Windows のシステム音声は実機で未確認です | 🟡 | リハで確認してください。だめならステレオミキサーかライン入力を使ってください |
| C5 | file:// で開くと、マイクの許可を毎回聞かれることがあります（Chrome の仕様） | ⬜ | 起動時に一度「許可」を押してください |
| C6 | 出力ウィンドウの全画面化は自動ではできません（ブラウザの制約）。プロジェクター側へ自動で開くには「ウィンドウの管理」の許可が必要です | ⬜ | 出力ウィンドウをダブルクリックするか F キーを押してください |
| C7 | 光過敏テストは WCAG 2.3.1 の近似です（4×3 の領域ごとの平均輝度）。赤のフラッシュの判定は色相で行っています | 🟡 | 会場に「光の点滅があります」と掲示してください。必要なら「フラッシュを一切使わない」を使ってください |
| C8 | テンポは極端に遅い・速い曲、変拍子、テンポが揺れる曲では外れることがあります | ⬜ | タップテンポ（Enter を 3 回以上）で上書きできます |
| C9 | ロゴ画像は設定（localStorage）に保存するので、大きいと保存に失敗することがあります | ✅/🟡 | 長辺 1024px に縮小して保存し、失敗したら警告を出します。書き出し・読み込みで別の PC にも移せます |
